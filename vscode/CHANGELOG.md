# Changelog

## 0.4.0

- Released with Redcliff 0.4.0 (Model mode and growing a model in the playground; `redcliff model
  extend`). The extension itself is unchanged and still needs Redcliff 0.3.0 or later.

## 0.3.0

- First release: the pipeline canvas beside the spec, column lineage on hover, blast radius on
  click, jump from a step or an issue to its YAML, problems in the editor, and generated Spark SQL,
  PySpark and DuckDB SQL. Needs Redcliff 0.3.0 or later (`pip install redcliff`).
